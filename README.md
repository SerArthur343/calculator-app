# calculator-app
A modern and interactive calculator application developed using HTML, CSS, and JavaScript. Designed with a sleek dark theme and glassmorphism effects, providing a clean and intuitive user experience.

## Features
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Percentage calculations
- Parentheses support
- Decimal number support
- Clear (C) and Delete (D) functions
- Error handling for invalid expressions
- Responsive and interactive button design
- Smooth hover and click animations
- Floating-point precision adjustment

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Design
- Dark gradient background
- Glassmorphism UI
- Rounded calculator buttons
- Smooth transitions and interactive effects
